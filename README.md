# Min lärardashboard med direktredigering

## Funktioner
- Schemabild med zoom 100 till 400 procent och dragfunktion.
- Datum och digital klocka.
- Checklistblock som redigeras direkt i dashboarden.
- Textanteckningar som skrivs direkt i dashboarden.
- Rubriker och checklistpunkter kan ändras direkt.
- Automatisk lokal lagring samt offline-stöd.

## Publicera
Packa upp ZIP-filen och ladda upp allt innehåll i mappen till roten av ditt GitHub-repository. Ersätt befintliga filer, klicka på Commit changes, vänta på GitHub Pages och ladda om sidan med Ctrl+F5.
