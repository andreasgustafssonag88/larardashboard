# Min lärardashboard med större text

Denna version har större text i blockrubriker, checklistpunkter, nya punktfält och textanteckningar. Direktredigering, schemazoom, lokal lagring och offline-stöd finns kvar.

## Publicera
Packa upp ZIP-filen och ladda upp allt innehåll till roten av GitHub-repositoryt `larardashboard`. Ersätt befintliga filer, klicka på Commit changes, vänta på GitHub Pages och ladda om sidan med Ctrl+F5.
