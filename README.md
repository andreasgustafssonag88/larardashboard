# Min kompakta lärardashboard

## Publicera och installera

Webbappen måste köras via HTTPS eller localhost. Publicera alla filer i denna mapp på exempelvis GitHub Pages eller en webbserver. Öppna sedan webbadressen i Microsoft Edge och välj **... > Appar > Installera den här webbplatsen som en app**.

## Lokala data

Schemabild, kalenderhändelser och anteckningar sparas lokalt i webbläsaren. De finns kvar när fönstret stängs, men synkroniseras inte automatiskt till andra enheter. Undvik känsliga elevuppgifter.

## Lokal test

Kör `python -m http.server 8080` i mappen och öppna `http://localhost:8080`.
